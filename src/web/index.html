About the tax content

Several positions this tool reports depend on how the UK/US double tax treaty is read, and qualified practitioners disagree about some of them. A treaty position is an argument, not settled law: HMRC or the IRS may take a different view, published guidance changes, and the outcome can turn on elections and filings made years ago that this tool cannot see.

Nothing here has been reviewed by a US-qualified tax adviser. Consulting a tax lawyer or dual-qualified adviser is strongly recommended before acting on anything this tool reports — and in particular before assuming a wrapper is safe because it is marked OK. This is information, not advice, and it is not a substitute for advice on your own circumstances.

Privacy notice

The short version

This page does not collect your data, because it cannot. It is a static file with no server behind it. Everything happens in your browser and stops when you close the tab.

What happens to a file you choose

It is read by this page using your browser's file API and held in the tab's memory. It is parsed, redacted and analysed there. It is not transmitted, copied, logged or stored. Nothing is written to disk unless you press a Download button, and that writes only to your own machine. Reloading the page discards everything.

How you can verify that, rather than take our word for it

This page sets a Content-Security-Policy of connect-src 'none', which instructs your browser to block every network request this page might attempt — fetch, XHR, WebSocket and beacon alike. Even if the code tried to send your data somewhere, the browser would refuse. You can confirm it yourself: open your browser's developer tools, go to the Network tab, and use the tool. You will see no requests. The source is public, as is the exact file this page serves.

Cookies, storage and analytics

None. No cookies, no localStorage, no sessionStorage, no IndexedDB, no service worker, no analytics, no tracking pixels, no third-party scripts, no fonts loaded from anywhere. The page loads two files — this document and one script — both from this domain.

Hosting

Served by GitHub Pages. GitHub receives the ordinary request information any web server does — your IP address, browser type and the page requested — under GitHub's own privacy statement. That is unavoidable for any hosted page and applies to the page request only; it never includes your financial data, because your financial data never leaves the tab.
